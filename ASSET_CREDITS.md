## Audio — fully synthesised

All 23 sound effects and 2 music loops are generated by
`tools/generate_audio.py`, a dependency-free Python script (22050 Hz, 16-bit
mono) that builds each sound from oscillators, filtered noise and envelopes:

| Group | Files |
| ----- | ----- |
| UI | `ui_hover`, `ui_click`, `ui_back` |
| Combat | `punch_light`, `punch_heavy`, `block`, `whiff`, `dash`, `jump`, `land` |
| Signature | `yeet_charge`, `yeet_impact`, `ko_hit` |
| Feedback | `combo_up`, `count_beep`, `go`, `error` |
| Arena | `arena_warning`, `hazard_warn` |
| Outcomes | `victory`, `defeat`, `submit_ok`, `submit_err` |
| Music | `music_menu` (≈16 s chill synth loop), `music_match` (≈15 s driving combat loop) |

Regenerate at any time:

```bash
python tools/generate_audio.py
```

No third-party samples, loops or libraries are used. Music loops by replaying the
bed when it finishes (see `game/scripts/audio/audio_manager.gd`).

### Provenance note

This project was rebuilt from scratch as a clean-room Godot 4 + FastAPI
implementation. An earlier HTML/JS/Express prototype of the same game concept
was not available in this environment (no copy of it could be located), so the
mechanics were re-implemented from the design description — combo scaling,
input buffering, the shrinking cage, YEET, the six-fighter roster — rather than
ported line-by-line. Nothing in this repository is copied from that prototype or
from any other game.
